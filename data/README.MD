# Data Sources

## Earthquake Catalogue
- Source: USGS Earthquake Catalog
- Minimum magnitude: 2.5
- Temporal coverage: 1 January 2000 – 8 November 2026
- Website: https://earthquake.usgs.gov/earthquakes/search/

## Geological Faults
- USGS fault dataset, extracted to the study area.
- Institute of Marine Affairs (IMA), Trinidad and Tobago Onshore Geological Faults.
